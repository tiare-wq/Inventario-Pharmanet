# Pharmanet
Repositorio de evaluación grupal.

<br/>

## Caso de Negocio
Una cadena de farmacias desea mejorar su sistema de inventario implementando una plataforma digital. Tiene el objetivo de tener el stock actualizado y evitar errores manuales.

<br/>

## Objetivo técnico
El repositorio demuestra:
- organización de una aplicación orientada a la gestión de inventario y logística farmacéutica
- modelado de entidades y relaciones para representar información del dominio
- implementación de operaciones CRUD para la administración de datos
- separación entre presentación, lógica de negocio y acceso a datos, si está implementada
- validación de datos de entrada para mantener la consistencia de las operaciones
- persistencia de información mediante una base de datos relacional, si corresponde
- desarrollo de funcionalidades orientadas al control y consulta de productos
- utilización de Git y GitHub para el control de versiones y colaboración
